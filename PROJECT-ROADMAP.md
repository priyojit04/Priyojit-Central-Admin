# Integration roadmap

1. Run this Central Admin locally and verify owner login.
2. Connect CarePoint first using a dedicated project API key and signed server-to-server requests.
3. Add integration endpoints for appointment counts and patient events.
4. Connect each remaining project only after its backend is implemented.
5. Add project-specific admin screens only through least-privilege APIs.
6. Deploy the central service and database with HTTPS, secrets management, backups and audit monitoring.

The eight registry entries are planning records, not live integrations.
